# DesktopCat

맥 화면(모든 연결된 모니터 포함) 위를 자유롭게 돌아다니는 픽셀 고양이 데스크탑 펫들.
지금 배포/운영 중인 프로젝트마다 고양이 한 마리씩, 이름표를 달고 따로따로 돌아다니며,
클릭하면 그 프로젝트의 진행상황 요약을 보여준다.
투명 오버레이 창이라 평소엔 다른 앱 작업을 방해하지 않지만, 클릭을 받아야 하므로 고양이 창 영역(작은 사각형)만은 클릭스루가 아니다.

## 동작 방식

- 프로젝트당 고양이 한 마리, 각자 독립적으로 배회/추격 상태를 가짐
- **평소**: 랜덤한 지점으로 어슬렁어슬렁 걸어갔다가 잠깐 앉아서 쉬는 걸 반복 (배회)
- **마우스 커서가 가까이 오면** (반경 약 220pt): 커서를 향해 달려가서 근처(약 42pt)에 도착하면 다시 앉음 (추격)
- 커서가 갑자기 멀리 점프하면(다른 화면/스페이스로 이동 등) 추격을 포기하고 다시 배회 모드로 전환
- 이동 방향에 따라 좌우로 스프라이트가 flip되고, 꼬리 흔들기/눈 깜빡임 애니메이션이 상태에 따라 다른 속도로 재생됨
- `NSScreen.screens`의 합집합 영역을 기준으로 움직이므로 모니터가 여러 대여도 전체 화면을 넘나듦
- 시작할 때 화면 가로로 고르게 흩어져서 스폰되므로 처음부터 겹쳐 있지 않음

## 배포 프로젝트 로스터

`~/.desktopcat/projects.txt`에 한 줄에 프로젝트 이름 하나씩 적혀 있고, 앱 시작 시 그 줄 수만큼 고양이를 만든다.
파일이 없으면 2026-08-09 기준으로 스캔한 기본 로스터(아래)로 자동 생성됨:

```
원카드 배틀
두터치
오늘의 운세
쓸모도구
GoLooply
직장인앱공장
desktopcat
process-guardian
App Store Review Miner
Copy+10% Idea Validator
```

`01-수익화-자산-현황.md` / 마스터플랜 / 최근 세션 기록을 기준으로 **실제로 라이브인 자산만** 골랐다 —
`review`(심사 대기: luck-lab, keycap-lab), `killed`(fortune-widget), `idea`(snapcam, BUYMA),
프로토타입(recovery-war), 프로젝트 폴더가 없는 자산(Gumroad 월페이퍼팩, 옵티몬 지식자산)은 제외했다.
onecard-battle은 iOS/Android는 스토어 심사 대기 중이지만 웹 버전(GitHub Pages)이 이미 라이브라 포함.
상태가 애매하거나 다음 액션이 불분명한 자산은 로스터에서 빼는 대신 **색상 고양이**(아래)로 표시한다.

로스터를 바꾸는 가장 쉬운 방법은 **설정 패널**(아래)의 리스트+입력창 — 앱을 켠 채로 즉시 고양이가 생기거나 사라진다.
파일을 직접 고치거나 `projects/DesktopCat/bin/catproject "새 프로젝트 이름"`으로 줄을 추가하는 것도 여전히 가능하지만, 그 경우는 앱을 재시작해야 반영된다.

## 상태 색상 (고양이 털 색)

고양이 털 색으로 그 프로젝트가 "지금 어떤 종류의 관심이 필요한 상태인지" 한눈에 보여준다.
배회·추격 같은 행동은 색과 무관하게 완전히 동일 — 순수하게 시각적 표시일 뿐이다.

| 색 | 의미 | 기준 |
|---|---|---|
| ⚪ 하얀색 (기본값) | 애매/미정 | 아직 상태를 분류하지 않았거나, 계속 진행할지 자체가 불명확함 |
| 🔴 빨간색 | 정지 | 다음 액션이 불분명한 채로 며칠~몇 주째 아무도 안 건드리고 있음 |
| 🟡 노란색 | 대기중 | 내가 할 일은 다 했고, 외부(심사·승인·인증 등)의 응답만 기다리는 중 — 지금 당장 할 액션 없음 |
| 🔵 파란색 | 진행중 | 계속 손으로 작업해야 진도가 나가는 활성 작업(버그 수정, 콘텐츠 제작, 기능 개발 등) |
| 🟢 초록색 | 자동가동 | launchd 등으로 예약되어 손 안 대도 알아서 돌아가는 무인 파이프라인 — 건강하게 자동 가동 중이라는 뜻 |
| 🟣 보라색 | 완료/유지보수 | 이미 완성돼서 로드맵상 추가 개발 계획은 없고, 버그 나올 때만 손대는 상태 |

- 목록은 `~/.desktopcat/status.txt`에 `프로젝트명=색상` 한 줄씩 저장(파일 없으면 2026-08-09 스냅샷 기준 기본값으로 자동 생성)
- 설정 패널의 프로젝트 리스트에서 각 행 오른쪽의 이모지 드롭다운으로 바로 바꿀 수 있음 — 다음 pose 갱신(1틱 이내)에 즉시 반영, 재시작 불필요
- 2026-08-09 기준 색상: 원카드 배틀🔵("친구와 하기" 버그 수정 + 테스터 11명 모집 진행중) · 두터치🔴(릴리즈 버튼 눌렀는지 3주+ 미확인) · 오늘의 운세🔴(6주 룰 판정 기산일 불확실) · 쓸모도구🔴(외부 방문 0건 확인 후 보류) · GoLooply🟢(launchd 완전 무인 가동, node_modules 보호 완료) · 직장인앱공장🔵(저빈도지만 계속 직접 제작) · desktopcat🔵(지금도 계속 확장 중) · process-guardian🟣(완결, 버그 나올 때만 유지보수) · App Store Review Miner🟡(Apify 신원인증 + r/SideProject 승인 대기) · Copy+10% Idea Validator🟡(claude-marketplace.com + Agensi 리뷰 대기)

## 진행상황 요약 (클릭)

고양이(또는 이름표)를 클릭하면 그 프로젝트의 진행상황 요약을 다이얼로그로 보여준다.
요약 텍스트는 `~/.desktopcat/summaries/<프로젝트 이름>.txt`에 저장되며, 앱 첫 실행 시
로스터에 있는 프로젝트마다 기본 요약(2026-08-09 스캔 기준)으로 자동 생성된다.
내용이 오래되면 해당 파일을 직접 열어 수정해도 되고, 설정 패널 리스트의 **편집** 버튼(아래)으로
앱 안에서 바로 고쳐도 된다 — 어느 쪽이든 **바로 반영됨(재시작 불필요)**, 클릭할 때마다 그 시점
파일 내용을 새로 읽는다.

## 설정 패널

메뉴바 🐱×N 아이콘을 **좌클릭**하면 설정 패널이 뜬다(다시 좌클릭하면 닫힘):
- **ℹ️ 사용법 보기**: 맨 위 버튼. 모든 기능을 한 페이지로 정리해서 보여준다 — 처음 켰을 때 이것부터 누르면 됨
- **프로젝트 리스트**: 지금 로스터에 있는 프로젝트 이름들. 행을 클릭하면 아래 입력창에 이름이 채워짐(제거할 때 편함). 각 행의 **이모지 드롭다운**(⚪🔴🟡🔵🟢🟣)으로 그 고양이의 상태 색을 바로 바꿀 수 있고, 오른쪽의 **편집** 버튼을 누르면 그 프로젝트의 진행상황 요약을 텍스트 박스로 열어 바로 고치고 **저장**할 수 있음(취소도 가능)
- **입력창 + 추가/제거 버튼**: 이름을 입력하고 **추가**를 누르면 그 자리에서 새 고양이가 스폰됨(랜덤 위치). 이름을 입력(또는 리스트에서 선택)하고 **제거**를 누르면 해당 고양이가 즉시 사라짐. 둘 다 `~/.desktopcat/projects.txt`에 바로 저장됨
- **마우스 추격**: 끄면 어떤 고양이도 커서를 쫓아가지 않고 배회만 함. 추격 중에 꺼도 즉시 멈춤
- **클릭 시 진행상황 요약 보기**: 끄면 고양이를 클릭해도 아무것도 뜨지 않음
- **왼쪽 정렬 (고정)**: 켜면 모든 고양이가 화면 왼쪽 가장자리에 세로로 일렬(90pt 간격)로 빠르게(420pt/sec — 추격보다도 빠름) 달려가서 도착한 자리에 멈춘다. 배회·추격 모두 무시함. 끄면 그 자리에서 바로 다시 평소처럼 돌아다님. 정렬된 상태에서 고양이를 추가/제거하면 줄이 자동으로 다시 채워짐. 줄 영역은 Dock·메뉴바를 제외한 화면(`visibleFrame`) 안에서만 계산되므로 맨 아래 줄이 Dock 뒤로 가려지지 않음
  - 체크하면 바로 옆에 **목록 보기** 버튼이 나타난다. 눌러서 뜨는 체크리스트에서 특정 고양이를 체크하면, 그 고양이는 줄서기에서 빠지고 평소처럼(배회/추격) 자유롭게 돌아다닌다 — 나머지 체크 안 된 고양이들만 왼쪽에 정렬됨
- **고양이 크기**: 0.5x / 1x / 1.5x / 2x 중 하나를 고르면 모든 고양이가 그 크기로 즉시 다시 태어난다(같은 자리·이름·상태색 유지). `~/.desktopcat/scale.txt`에 저장되어 재시작해도 유지됨. **왼쪽 정렬** 모드일 때는 줄 간격(가로·세로 모두)도 크기에 비례해서 같이 커지므로 확대해도 서로 겹치지 않음
- **화면 맨 뒤로 이동**: 켜면 모든 고양이가 데스크탑 아이콘과 같은 레벨로 내려가서, Finder·브라우저 같은 일반 앱 창이 항상 고양이보다 위에 그려진다 — 창 뒤 버튼을 고양이가 가려서 못 누르는 문제 해결용. 바탕화면(다른 창이 없는 영역)에서는 그대로 보이고 클릭도 됨. 끄면 다시 항상 최상단(다른 창 위)으로 복귀
- **업데이트 확인**: 누르면 그 자리에서 GitHub Releases를 확인해 새 버전이 있으면 설치까지 도와준다. 버튼 옆의 작은 "최신: vX.X.X" 표시는 그것과 별개로 **매일 자정(로컬 자정)마다 자동으로** 조용히 확인해서 갱신되는 값 — 그냥 지금 최신 배포 버전이 몇인지 훑어보는 용도라 눌러도 아무 일 안 일어남. 값은 `~/.desktopcat/latest_version.txt`에 캐시되어 앱을 껐다 켜도 바로 표시됨
- Quit Desktop Cat 버튼도 패널 안에 있음

아이콘을 **우클릭**하면 별도로 빠른 종료 메뉴가 뜬다.

## 실행

```bash
cd projects/DesktopCat
swift build -c release
./.build/release/DesktopCat &
```

로그인 시 자동 실행을 원하면 `.build/release/DesktopCat`을 LaunchAgent(`~/Library/LaunchAgents`)로 등록하면 된다 (요청 시 추가 작업 가능).

## 구현 메모

- 순수 AppKit(Swift Package, Xcode 프로젝트 아님). 이미지 에셋 없이 `CatSprite.swift`에서 16x16 픽셀 그리드를 코드로 그려 캐싱한 `NSImage`를 사용. 상태 색상은 별도 이미지가 아니라 같은 그리드를 `CatStatus`별 fur 색으로 한 번씩 더 렌더링해 캐싱해둔 변형 프레임 세트(포즈×좌우flip×6색)를 골라 쓰는 방식.
- 창은 `borderless` + `level = .floating` + `collectionBehavior = [.canJoinAllSpaces, ...]`로 모든 Space 위에 떠 있다. 클릭을 받아야 해서 `ignoresMouseEvents = false`로 바뀌었고, 클릭은 `NSAlert` 모달로 요약을 띄운다 — 그동안 다른 고양이들의 애니메이션은 잠깐 멈췄다가 닫으면 재개됨.
- 마우스 위치는 전역 이벤트 모니터 대신 `NSEvent.mouseLocation` 폴링(30fps 타이머)으로 읽는다 — 별도 손쉬운 사용/입력 모니터링 권한이 필요 없다.
- 스프라이트는 지금은 정면 앉은 포즈 1종 + 좌우 flip + 꼬리/눈 변형 프레임으로 "걷는 느낌"을 낸다. 8방향 전용 걷기 스프라이트(위/아래/옆모습)를 따로 그려 넣으면 애니메이션을 더 다듬을 수 있음 — 필요하면 다음 단계로 추가 가능.
